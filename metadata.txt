description=Parallel rendering of QGIS print layouts and atlases (PNG, JPG, TIFF, BMP, PDF, SVG).
about=MultiRender takes the layouts from the Layout Manager and renders them in parallel, each in its own qgis_process process, using all CPU cores without blocking QGIS. Atlases and multi-page layouts can be split into parts rendered at the same time. Before rendering, remote and database layers are fetched once into a local cache shared by all prints. For each layout you choose the format, DPI, page range and output folder; settings are remembered and the results can be packed into a ZIP archive. A built-in performance analysis shows which layers and stages slow rendering down. Interface languages: English, Polish, German, Spanish, French.
